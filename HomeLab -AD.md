### HomeLab - Projects & Documentation

### Project 1 - Active Directory HomeLab Exercise

  What is this? 
  
    - Active Directory self-learning lab
  Why build this?
  
    - To get hands-on AD experience and experience with Virtualization
    
  Hardware/Software Used
  
      -2020 MacBook Air Dual-booting into Windows 10 Pro
      -Windows Server 2025 iso
      -VirtualBox software
  SetUp
  
      -Downloaded VirtualBox software and Windows Server ISO; set Network to Bridged Adapter to be discoverable on home network
      -Configured VM Server Role to Active Directory Domain Services
  Problems and Fixes
  
      -Dual-booted Windows was missing dependencies for VirtualBox - Fixed by downloading/installing Microsoft Visual C++  
  Next
  
      -Set up OU's, security groups, and group policy for fictional corporate environment
